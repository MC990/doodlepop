# DoodlePop

Versión web interactiva basada en **DoodlePop V13 (MASTER)**.

## GitHub Pages
El archivo de entrada es `index.html`.

Mantén todos los archivos y carpetas de assets junto a `index.html` con la misma estructura relativa.

## Readymag
Una vez publicado con GitHub Pages, usa la URL pública del sitio como `src` de un iframe.

V13 es la versión MASTER aprobada. Conserva una copia intacta antes de futuras modificaciones.
